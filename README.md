# CodSoft Task 5 – Rock-Paper-Scissors Game

## 📌 Project Overview

This project is **Task 5 of the CodSoft Python Programming Internship**.

The **Rock-Paper-Scissors Game** is a Python-based game where the user plays against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is decided based on the game rules.

## 🚀 Features

* Play against the computer
* Random computer choice
* User-friendly interface
* Displays the winner
* Keeps track of the game result
* Simple and easy-to-use design

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – Graphical User Interface
* **Random** – Computer's random choice

## 🎯 Objective

The main objective of this task is to develop a simple interactive game while improving Python programming, logic building, and GUI development skills.

## 📚 Learning Outcome

Through this task, I learned:

* Python programming
* Conditional statements
* Random module
* Game logic
* GUI development using Tkinter
* User input and event handling
